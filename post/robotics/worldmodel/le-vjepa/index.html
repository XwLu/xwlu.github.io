阅读导览：这篇论文解决了什么问题？

LeVJEPA 希望用大量无标签视频，以较低计算成本训练出通用视觉编码器，同时保留静态外观识别和运动理解能力。

核心方法可以记成两句话：

  1. 同一视频的不同视图，应该产生接近的特征。
  2. 不同视频的特征作为一个整体，应该形成接近标准高斯的分布。

第一条负责学习视图之间的稳定信息，第二条防止所有输入都被映射成同一个向量。这样，训练结构可以简化为共享编码器和小型投影头，不再依靠教师目标编码器、预测器和 stop-gradient 来避免塌缩。

在这个目标下，作者发现：训练时随机丢掉 95% 的 patch token，既节省计算，又能提高 ImageNet 识别效果；编码器还可以使用遵守时间顺序的注意力，而在所报告的 ImageNet 消融中没有损失精度。

本文最重要的贡献是视频自监督预训练的简化与计算效率。 它训练的是视觉表征基础；动作条件动力学、未来状态预测和车辆规划还需要对应的模型与训练目标。

1. Introduction：为什么重新设计视频预训练？

1.1 视频提供了图片缺少的时间结构

图片主要提供物体、场景和外观信息。视频还包含运动方向、动作过程、跨帧身份一致性和物体持续存在等信息。

以自动驾驶为例：单帧可以识别路边有一辆车；连续观察才更容易判断它正在停车、驶出车位，还是准备切入本车道。

这些时间线索使视频适合用于视觉预训练。不过，视频中含有时间结构，不等于某个训练目标一定会充分学到它；运动评估仍然是必要证据。

1.2 计算成本来自视频长度和额外训练结构

Patch 是图像中的小块；token 是小块经过嵌入层后得到、供 Transformer 处理的向量。

一帧 $224\times224$ 图片按 $16\times16$ 切块，得到

$$14\times14=196$$

个 patch。16 帧就有

$$16\times196=3136$$

个 patch token。视频本身已经比单张图片昂贵。

此外，V-JEPA 一类方法还使用提供训练目标的编码器副本和预测器。教师的完整输入前向、预测器计算以及相关训练配置进一步增加成本。

1.3 表征塌缩是需要处理的核心问题

表征或 embedding：模型将输入映射成的特征向量。

如果只要求同一视频的两个视图输出一致，模型可以对所有视频都输出零向量。这满足一致性，却丢失了区分输入的能力，称为完全塌缩。

还有一种情况：输出看似有变化，但只沿少数方向变化，其他方向完全没有信息，称为维度塌缩。

LeVJEPA 采用显式分布约束处理这个问题，并据此重新考察 token 丢弃方式、时间 patch 聚合和注意力结构。

1.4 作者希望获得的三个性质

性质 实际含义
训练计算效率 Transformer 只处理很少的保留 token，也不需要目标教师和预测器前向
时间顺序约束 每帧的 patch 表征只依赖当前和过去观测
简单训练目标 一致性损失加 SIGReg，损失权重固定使用已有默认值

论文中的"一个超参数"指损失中的一个权衡系数。学习率、batch size、模型规模、视图数量和丢弃率等训练设置仍然存在。

2. Related Work：相关工作的四条路线

2.1 图片自监督：匹配同一输入的不同视图

自监督学习指训练信号从数据自身的结构中构造，不需要给每个预训练样本人工标注类别。

**联合嵌入（joint embedding）**方法将同一输入的不同视图映射到特征空间，并要求它们表达一致。

方法 与本文相关的特点
BYOL 在线网络匹配缓慢更新的目标网络，通过分支不对称设计训练
DINO 教师—学生结构，配合中心化、锐化和全局—局部多裁剪
DINOv2 延续这一体系，结合掩码图像建模并扩大训练规模
I-JEPA 在特征空间预测被遮挡区域，而不是恢复其像素

相关术语：

  • EMA（指数移动平均）目标编码器：使用在线模型参数的平滑平均，生成训练目标。
  • Stop-gradient（停止梯度）：目标分支参与数值计算，但损失不沿该分支反向传播。
  • Predictor（预测器）：将可见信息的特征转换成需要预测的目标特征。

LeVJEPA 采用全局—局部视图构造，但用 SIGReg 承担防塌缩约束。

2.2 显式特征统计约束：从二阶统计到完整分布目标

VICReg 将一致性、方差和协方差约束结合起来；Barlow Twins 通过跨视图相关性约束减少冗余。这类方法不必使用教师网络和 stop-gradient。

LeJEPA 进一步提出一个分布目标：在其采用的下游 probing 风险模型及假设下，各向同性高斯具有理论依据，并给出 SIGReg 来近似约束这一分布。

Probing 是冻结预训练编码器，仅训练一个较小的读取或分类模块，以考察表征中包含多少下游任务信息。

LeVJEPA 使用的 SIGReg 来自 LeJEPA，本文的工作是将这一配方用于视频，并研究由此获得的简化和效率收益。

2.3 像素重建：VideoMAE 与 tube masking

VideoMAE 遮挡大量视频 patch，再恢复被遮挡的像素。

视频的相邻帧高度相似。如果每帧独立遮挡，当前帧缺失的内容可能直接从邻帧复制，重建任务就过于容易。

Tube masking 在连续帧中遮挡相同的空间位置，减少这种捷径，支持 90%—95% 的高遮挡率。VideoMAEv2 进一步引入解码器侧的掩码以扩大训练规模。

本文强调：遮挡方式应服务于训练目标。适合像素重建的 tube 结构，在不进行内容重建的 LeVJEPA 中未必合适。

2.4 特征预测与视频世界模型

V-JEPA 根据可见部分预测被遮挡部分的特征，目标由 EMA 编码器生成。V-JEPA 2 扩展了训练数据、模型大小、训练长度及分辨率。

用于规划的 V-JEPA 2-AC 还会冻结视觉编码器，在机器人交互数据上训练动作条件、block-causal 的预测模型，输入包含动作和机器人状态等信息。

论文也讨论了像素空间的动态生成路线，以及基于预训练特征的世界模型。

LeVJEPA 将时间顺序约束放入视觉编码器预训练。它提供了符合在线观测条件的状态表征基础，但没有在本文中训练动作条件状态转移模型。

3. Methodology：训练方法、结构与关键机制

3.1 符号与数据流

符号 含义
$B$ 一个 batch 的视频片段数
$T$ 视频帧数，预训练默认 16
$H,W$ 视图的空间高、宽
$V$ 局部视图数量，默认 4
$\tau$ patch embedding 覆盖的时间长度，默认 1 帧
$\rho$ 丢弃的 patch token 比例，默认 0.95
$d$ 编码器 token 的特征维度
$K$ 投影后特征维度，默认 256
$E_\theta$ 参数为 $\theta$ 的共享视频编码器
$h_\phi$ 参数为 $\phi$ 的共享投影头
$z_v$ 第 $v$ 个视图投影后的特征

每个训练视频采样 16 帧，构造 1 个全局视图和 $V$ 个局部视图。所有视图共享完全相同的时间窗口，仅在空间裁剪及外观增强上不同。

项目 全局视图 $x_0$ 局部视图 $x_1,\ldots,x_V$
默认数量 1 4
默认分辨率 $224\times224$ $96\times96$
时间窗口 16 帧 同一组 16 帧
空间处理 较完整的观察 激进空间裁剪
光度处理 保持光度不变 进行光度增强
Patch 丢弃率 95% 95%

光度增强改变亮度、颜色等外观属性；具体参数在本地版本中未完整列出。

每个视图执行：

视频视图
  → patch embedding
  → 均匀随机丢弃 patch token
  → 加入可学习 CLS token
  → 共享视频 Transformer
  → 读取输出 CLS
  → 共享投影头
  → 用于计算损失的 z

数学表达为：

$$z_v=h_\phi\!\left(E_\theta(x_v)_{[\mathrm{CLS}]}\right)\in\mathbb R^K.$$

这里 $E_\theta(x_v)$ 隐含了 patch embedding、丢弃及注意力处理。所有视图共享同一组 $\theta,\phi$。

概念张量形状

下面使用常见的维度顺序帮助理解，实际代码的维度排列可以不同：

阶段 单个视图对应的 batch 形状
RGB 视频输入 $B\times T\times3\times H\times W$
Patch embedding 后 $B\times N_v\times d$
丢弃后并加入 CLS $B\times(L_v+1)\times d$
编码器输出 $B\times(L_v+1)\times d$
CLS 输出 $B\times d$
投影后 $B\times256$

其中 RGB 表示三个颜色通道；$N_v$ 是原始 patch 数，$L_v$ 是保留 patch 数。对于可整除的默认尺寸：

$$N_v=\frac{T}{\tau}\frac{H}{16}\frac{W}{16},\qquad L_v\approx(1-\rho)N_v.$$

具体整数取整方式正文未说明，因此下文保留 token 数使用近似值。

3.2 一致性损失：匹配同一视频的不同观察

论文原式为：

$$\mathcal L_{\mathrm{inv}}=\frac{1}{V+1}\sum_{v=0}^{V}\|z_0-z_v\|_2^2.$$

$z_0$ 是全局特征，$z_v$ 是局部特征；$\|\cdot\|_2^2$ 表示各特征分量差值的平方和。$v=0$ 的一项为零。实际训练还会在 batch 上归约，具体实现细节正文未完整说明。

全局视图覆盖范围最大、没有光度增强，因此通过视图构造自然成为匹配参考。

全局与局部分支都接收梯度。 全局特征由同一个正在学习的编码器生成，没有停止梯度，也没有单独的目标教师。

以"汽车通过路口"的视频为例，全局观察看到路口，局部观察可能只看到汽车与附近道路。为了输出接近的特征，模型需要从不同残缺观察中提取共同内容。

不过，这个解释是训练的归纳偏置，不是对具体语义的硬性保证。相同输出也可以通过全部变成常量实现，因此还需要防塌缩约束。

3.3 SIGReg：约束一批特征的分布

SIGReg 通过随机投影约束各向同性高斯分布：对高维特征沿随机方向投影，约束这些一维投影匹配标准高斯。

其整体目标是：

$$z\sim\mathcal N(0,I_K).$$

$\mathcal N$ 表示高斯分布，$0$ 是零均值向量，$I_K$ 是 $K$ 维单位矩阵。

这个目标描述的是很多视频特征共同形成的分布。 它没有为每个视频随机分配一个必须拟合的高斯标签，也没有要求单个向量内部的 256 个数独立服从高斯。

3.3.1 各向同性、各向异性与塌缩

各向异性表示沿不同方向观察，统计性质不同。对于高斯点云，主要表现为不同方向的方差不同。各向同性表示任意方向上的分布性质相同。

直观类比：车辆定位误差如果纵向大、横向小，误差点云呈椭圆；若各方向误差分布相同，则呈圆形。这个例子解释的是统计形状，与模型特征每个维度的具体语义无关。

二维高斯例子：

$$\Sigma=\begin{bmatrix}9&0\\0&1\end{bmatrix}$$

表示两个坐标方向的方差分别为 9 和 1，点云沿第一个方向拉长。标准高斯 $\Sigma=I$ 则满足：对任意单位向量 $a$，

$$\operatorname{Var}(a^\top z)=a^\top I a=1.$$

本文的"方向"是 embedding 特征空间的方向，可以对应单个维度，也可以是多个维度的线性组合，与图像里的前后左右没有直接对应关系。

三种情况需要区分：

点云状态 含义
椭圆形，但协方差满秩 各向异性，仍可保留全部维度的变化
被压到直线或更低维仿射子空间 某些方向方差为零，出现维度塌缩
所有样本挤在同一点 完全塌缩

因此，普通各向异性不能直接等同于塌缩。

3.3.2 用随机投影检查高维分布

Cramér–Wold 定理给出如下刻画：

$$z\sim\mathcal N(0,I_K)\quad\Longleftrightarrow\quad a^\top z\sim\mathcal N(0,1)\quad\text{对所有单位方向 }a.$$

直觉是从很多方向观察点云的"影子”。如果点云被压成一条线，从垂直方向看，所有投影值就会挤在一起。

作者在每个训练步骤采样 $M=1024$ 个单位方向 $a_m\in\mathbb R^K$。对每个视图分别形成 batch 特征矩阵 $Z_v\in\mathbb R^{B\times K}$，再得到 $B\times M$ 的投影值。

理论要求所有方向；实际采用有限 batch、有限随机方向和数值积分近似优化。不能将其理解为每一步都精确满足标准高斯，也不能将防塌缩的分布目标扩大成对所有实际训练过程的无条件收敛保证。

3.3.3 特征函数与 Epps–Pulley 统计量

对于某个随机方向 $a_m$，设投影值：

$$u_i=\langle z_i,a_m\rangle,\qquad i=1,\ldots,n.$$

$n$ 是该视图参与统计的全局 batch 样本数。经验特征函数为：

$$\widehat\varphi_m(t)=\frac1n\sum_{i=1}^{n}e^{\mathrm i t u_i}.$$

其中 $\mathrm i$ 是虚数单位，$t$ 是频率变量，且：

$$e^{\mathrm i t u}=\cos(tu)+\mathrm i\sin(tu).$$

“特征函数"是统计学术语，指描述概率分布的函数，与神经网络的 feature 名称不同。可以将其理解为：用不同频率扫描这批投影值，形成描述分布的响应。

标准高斯的一维特征函数为：

$$\varphi_G(t)=e^{-t^2/2}.$$

SIGReg 比较经验响应和目标响应，论文公式为：

$$\mathcal L_{\mathrm{SIGReg}}=\frac1M\sum_{m=1}^{M}\int\left|\widehat\varphi_m(t)-e^{-t^2/2}\right|^2e^{-t^2/2}\,dt.$$

竖线表示复数模长；积分外的 $e^{-t^2/2}$ 是频率权重。公式对应基于经验特征函数的 Epps–Pulley 正态性统计量。

附录 A 的实现采用 $t\in[0,3]$ 上的 17 个节点，用梯形求积近似积分。每个视图单独计算统计量；视图间具体归约细节正文未展开。

3.3.4 为什么对异常特征值比较稳健？

核心直觉：异常值变得再大，也只会让单位圆上的箭头改变方向，箭头长度始终为 1。

相比之下，二阶矩中有 $u^2$，极大的 $u$ 会带来极大的统计贡献。

推导如下。每个复指数的模长满足：

$$|e^{\mathrm i t u_i}|=1,\qquad |\widehat\varphi_m(t)|\le1.$$

在固定其他投影值的前提下，单个样本对经验均值的贡献模长为 $1/n$；任意替换这个投影值，经验特征函数最多改变 $2/n$，与异常值的数值大小无关。

对样本投影值 $u_j$ 求导：

$$\frac{\partial\widehat\varphi_m(t)}{\partial u_j}=\frac{\mathrm i t}{n}e^{\mathrm i t u_j},\qquad\left|\frac{\partial\widehat\varphi_m(t)}{\partial u_j}\right|=\frac{|t|}{n}.$$

这里明确是对 投影输入 $u_j$ 求导。这个导数不会随 $u_j$ 的幅度增加。

令单频率平方误差为：

$$\ell_m(t)=|\widehat\varphi_m(t)-\varphi_G(t)|^2.$$

由于经验特征函数和目标特征函数模长都不超过 1，残差模长不超过 2，因而：

$$0\le\ell_m(t)\le4,\qquad\left|\frac{\partial\ell_m(t)}{\partial u_j}\right|\le\frac{4|t|}{n}.$$

采用权重 $w(t)$ 积分，只要 $\int |t|w(t)\,dt$ 有限，就能控制这项损失对投影值的梯度。本文使用高斯权重，实际又只采用有限范围的 17 个积分节点，满足这一要求。投影方向 $a_m$ 为单位向量，因此通过 $u_j=a_m^\top z_j$ 也可以控制该项损失对 embedding 的梯度。

对照二阶矩：

$$m_2=\frac1n\sum_i u_i^2,\qquad \frac{\partial m_2}{\partial u_j}=\frac{2u_j}{n}.$$

$u=1000$ 的平方贡献是 $u=1$ 的一百万倍，梯度也随 $u$ 线性增大。

因此，稳健性的准确含义是：极端特征值不会仅凭幅度巨大，就无限放大它对 SIGReg 统计量及相应输出特征梯度的影响。

这不表示异常样本完全无影响，也不保证整个网络的参数梯度全局有界，因为参数梯度还要经过网络 Jacobian。另一个一致性 MSE 项同样不自动获得 SIGReg 的有界性保证。

3.3.5 为什么 SIGReg 本身不需要中心化或白化？

中心化是将特征减去均值；白化进一步变换特征，使协方差成为单位矩阵。白化主要规范二阶统计，通常不会让任意非高斯分布变成高斯。

SIGReg 直接比较当前特征投影的分布与 $\mathcal N(0,1)$。均值偏移、尺度偏差、方向间的相关结构及更完整的分布形状差异，都受这个目标约束。

例如某方向：

$$u\sim\mathcal N(5,9).$$

它的特征函数为：

$$\varphi_u(t)=e^{5\mathrm i t}e^{-9t^2/2},$$

与目标 $e^{-t^2/2}$ 不同，直接计算 SIGReg 会产生惩罚。如果先做 $(u-5)/3$，这个高斯例子就已经被变换成标准高斯，原始输出的均值和尺度偏差被预处理消除了，损失不再直接看到这些偏差。

这个例子限定在高斯情形；不能据此认为任何分布标准化后都会变成高斯。

可以这样记忆：中心化、白化直接移动和拉伸当前点云；SIGReg 比较点云与目标分布的差距，再训练网络自己调整输出。

有限 batch 和数值近似下，每一步输出不必精确具有零均值、单位协方差。并且，SIGReg 本身无需这些预处理，不等于整个模型没有归一化：LeVJEPA 投影头明确包含 BatchNorm。

3.4 总损失与两个目标的配合

$$\boxed{\mathcal L=\mathcal L_{\mathrm{inv}}+\lambda\mathcal L_{\mathrm{SIGReg}}},\qquad\lambda=0.02.$$

作者沿用 LeJEPA 的默认权重，在本文所有实验中固定使用，没有逐实验调节。

一致性项使同视频的多个观察对齐，SIGReg 使整个视频集合的输出保持分布上的丰富变化。完全塌缩的输出不满足标准高斯目标；某个方向方差为零的维度塌缩同样不满足目标。

两者结合产生学习有用表征的倾向，最终表征质量由下游实验检验。仅有一个非塌缩、分布形状良好的点云，并不能单独证明它一定包含任务所需语义。

3.5 CLS token：共享的"汇总员"如何随视频变化？

CLS 是 Classification Token 的缩写。 它是模型额外添加的可学习向量，没有对应的图像区域。

输入可以写成：

$$[c,p_1,\ldots,p_{L_v}],$$

其中 $c\in\mathbb R^d$ 为可学习的 CLS 初始参数，$p_j$ 为保留的 patch token。

不同视频、不同视图使用同一个初始 CLS 参数；经过 Transformer 后，CLS 读取的 patch 内容不同，因此输出特征 $h_{\mathrm{CLS}}$ 也随输入内容变化。

可以类比同一位汇总员：开始时使用相同的工作模板，读完不同视频的记录，写出的总结自然不同。共享的是初始参数，不是最终总结。

每个视图得到自己的 CLS 输出，再经过共享投影头得到 $z_v$。一致性损失和 SIGReg 直接作用在投影后的 $z_v$ 上，不是直接在每个 patch 上设置目标。

不过，CLS 的汇总依赖 patch，所以损失仍会通过注意力路径反向传播至 patch 处理过程。没有直接 patch 损失，不代表 patch 不学习。

3.6 为什么末端 LayerNorm 后还需要投影头？

3.6.1 LayerNorm 与 SIGReg 的统计轴不同

**LayerNorm（层归一化，简称 LN）**对单个 token 的特征维度计算均值和方差；SIGReg 则约束很多样本形成的 embedding 分布。

所以，“每个向量内部均值为零、方差为一"不能推出"很多向量整体服从标准高斯”。前者是逐向量约束，后者是跨样本分布约束。

3.6.2 球面约束的推导及适用条件

对于 $x\in\mathbb R^d$，忽略数值稳定项 $\epsilon$ 和可学习仿射参数，定义：

$$\mu=\frac1d\sum_{j=1}^d x_j,\qquad\sigma^2=\frac1d\sum_{j=1}^d(x_j-\mu)^2,\qquad y_j=\frac{x_j-\mu}{\sigma}.$$

对于 $\sigma>0$ 的输入：

$$\sum_jy_j=0,\qquad \sum_jy_j^2=d,\qquad\|y\|_2=\sqrt d.$$

也就是所有输出位于固定半径球面与零和子空间的交集。直观上，原来长短不同的向量被整理到同一个球壳，并且受到零和约束。

沿单位方向：

$$a=\frac{(1,\ldots,1)}{\sqrt d}$$

投影时，$a^\top y=0$ 恒成立；这一方向的方差为零，无法满足标准高斯要求的单位投影方差。

实际 LayerNorm 包含 $\epsilon$ 和逐维可学习的 $\gamma,\beta$：

$$\operatorname{LN}(x)_j=\gamma_j\frac{x_j-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta_j.$$

$\epsilon$ 使固定范数不再严格成立，仿射参数会拉伸、平移几何形状。论文的"球面约束"描述的是归一化核心，不能字面理解为实际 LN 仿射输出永远位于一个标准球面。

3.6.3 投影头的作用

在保留编码器末端 LayerNorm 的原架构中，作者通过小型 MLP 将 CLS 输出映射到另一个空间。这个空间的最终输出不再被同一个末端 LN 强制成上述固定形式，便于近似优化高斯分布目标。

预训练后丢弃投影头，下游使用编码器表征。

“需要投影头"应理解为本文既定结构和目标下的选择，不能扩大为所有可行网络都必须有投影头。

3.7 高斯是否唯一？球面目标与删除末端 LN 的结论

3.7.1 球面均匀分布也可以非塌缩且各向同性

只要求向量位于球面，仍然允许所有向量挤在球面同一点；若采用球面目标，还需要推动样本在球面上均匀铺开。

均匀圆周分布提供了一个例子：二维半径为 $\sqrt2$ 的均匀圆周点云，其均值为零、协方差为 $I_2$，但它不是二维高斯。

它虽然位于一条曲线上，协方差仍可满秩。不能因为分布支撑位于曲面上，就认定发生了协方差意义上的维度塌缩。 圆周与直线不同，圆周没有某个非零方向的投影恒定不变。

3.7.2 为什么 LeJEPA 仍然选择高斯？

LeJEPA 在采用的下游 probing 风险模型及假设下，为各向同性高斯给出理论支持。线性分析主要支持各向同性，进一步的非线性风险分析支持高斯目标。

这个理论依赖其假设。单凭各向同性和防塌缩，无法推出目标必须是高斯，也不能推断高斯在所有实际任务中都必然优于球面分布。

3.7.3 球面版分布约束可以设计，但目标必须一起改变

随机投影加特征函数比较的思路可以用于其他目标分布。若选择球面均匀分布，需要把 $e^{-t^2/2}$ 替换成所选球面分布的一维投影特征函数，或与从目标球面采样得到的参考特征比较。

有限维球面的投影通常不是高斯，因此不能保留标准高斯的一维目标，却声称已经改成了球面目标。

如果直接匹配 LN 输出，还需要让目标分布适配 LN 允许的子空间及实际仿射变换。这属于替代方案，需要重新验证效果，也不能直接继承原高斯目标的最优性结论。

3.7.4 能否删除编码器最后的 LayerNorm？

可以，原理上合理，但本文没有对应消融。

只删除最末端 LN，会解除该操作施加的输出几何约束。保留 Transformer 内部 LN 并不等于最终输出仍固定在球面上。

以常见 Pre-LN 残差结构为例：

$$u_{\mathrm{next}}=u+\operatorname{Module}(\operatorname{LN}(u)).$$

其中 $u$ 是残差流，$\operatorname{Module}$ 表示注意力或前馈分支。内部 LN 规范分支输入，残差相加后的整体输出没有被这一式子强制归一化。

因此，直接对未做末端 LN 的编码器输出优化 SIGReg，在原理上可行。不过，末端 LN 有助于尺度控制；投影头也可能通过分开下游表征空间和训练损失空间产生收益。删除后是否需要调整优化配置、精度是否保持，都需要实验。

值得比较的三个方案是：原结构、只删末端 LN、同时删末端 LN 与投影头。删除末端 LN 能解除该几何冲突；投影头能否进一步省略，需要实验回答。 SIGReg 的软分布损失也不等于每次前向立即完成归一化。

3.8 编码器、稀疏观察和位置编码

3.8.1 逐帧 patch embedding

默认使用适配视频的 Vision Transformer。ViT-B/16 表示 Base 规模的 ViT，空间 patch 边长为 16；ViT-S、ViT-L 分别表示 Small、Large 规模。

时间尺寸默认 $\tau=1$，每个 token 只覆盖单帧 patch：

视图 原始 patch 数 丢弃 95% 后约保留
全局，16 帧、$224\times224$ 3136 157
局部，16 帧、$96\times96$ 576 29

默认 1 个全局加 4 个局部，合计约 $157+4\times29=273$ 个 patch token，此外每个视图各保留一个 CLS。

丢弃发生在 patch embedding 之后、Transformer 主体之前。被丢弃 token 不再占据主体序列中的位置，因此主体实际处理的序列变短。Patch embedding 仍需要先执行，不能把所有模块的成本都按 95% 等比例扣除。

训练没有重建被丢弃 patch 的目标，也没有用于恢复这些 token 的预测器或解码器。

3.8.2 三维旋转位置编码

**RoPE（旋转位置编码）**通过依赖坐标的旋转，在注意力计算中引入相对位置。

每个 token 具有时间、纵向和横向坐标 $(t,y,x)$。注意力头的特征维度分成三组，分别按三个坐标旋转。不使用绝对位置编码。

因此，同一个编码器能够处理全局和局部两种空间分辨率，无需对绝对位置编码做插值。

3.9 Block-causal attention 与在线推理

Block-causal attention 指以帧为块：帧内双向，跨帧遵守时间顺序。

查询 token 允许读取的内容
第 $t$ 帧 patch 当前帧所有 patch，以及历史帧 patch
第 $t$ 帧 patch 不允许读取未来帧，也不允许读取 CLS
CLS 可以读取整个片段的 patch

“读取"表示该 token 在注意力中将对方作为信息来源。

CLS 不允许被 patch 反向读取非常关键：如果 CLS 已经汇总未来帧，再让早期 patch 读取它，未来信息就可能绕路泄漏。

因此，每帧 patch 表征满足：

$$H_t=F_\theta(x_1,\ldots,x_t).$$

$H_t$ 表示第 $t$ 帧的 patch 表征，$x_{1:t}$ 是当前及历史观测。整个 clip 的 CLS 则汇总整个已输入片段，不能把它误认为早期每一帧都可使用的状态。

这种因果性表示信息不能跨越时间顺序，不直接等于识别了现实世界中的物理因果关系。

推理时如何使用？

作者的下游评估使用编码器输出，投影头丢弃，且不再进行训练中的 token 丢弃。

工程上，block-causal 结构允许新帧到来后复用历史 patch 的计算，而不必因新增未来观测而重新修改历史特征。可以配合 KV cache，即缓存注意力中的历史 Key、Value 张量，避免重复计算。

注意两个层面：

  • 不必重新编码过去帧，是因果结构直接带来的性质。
  • 如果历史无限增长，新查询仍要读取越来越多历史 KV，标准注意力的计算和缓存量仍会增长；固定历史窗口更容易获得近似固定的每帧成本。

因此，论文提及的增量成本优势不能直接理解为任意长视频、无限历史下所有注意力运算严格为常数。本文也没有给出完整在线系统的时延基准。

3.10 Polyak 平均：仅用于评估的平滑参数

3.10.1 平均的是同一个参数在不同训练时刻的值

模型中每个权重、偏置，分别与自己的历史数值平均。不会把不同层或不同位置的参数混在一起平均。

这与 PNC 中一阶低通滤波的递推形式相似：减少训练参数随优化产生的短期波动。这个类比解释的是平滑机制，不表示它与车辆状态滤波具有相同统计假设或最优性。

术语上，经典 Polyak 平均常指历史参数的等权平均；本文称为 Polyak average 的实现使用带衰减的 EMA。

3.10.2 EMA 更新公式

为区分平均更新次数与优化器步数，设 $k$ 是平均更新索引，$s_k$ 是本次平均更新对应的优化器步骤：

$$\bar\theta_k=\beta\bar\theta_{k-1}+(1-\beta)\theta_{s_k}=\bar\theta_{k-1}+(1-\beta)(\theta_{s_k}-\bar\theta_{k-1}).$$

$\theta_{s_k}$ 是当前训练模型参数，$\bar\theta_k$ 是保存的平均参数，$\beta$ 是衰减系数。第二种写法说明，每次平均参数向当前模型移动一小步。

示例取 $\beta=0.9$，平均参数初始为 10，当前参数依次为 14、8、12，则平均值依次为：

$$10.4,\quad10.16,\quad10.344.$$

历史已经累积在旧平均值中，不必保存所有历史 checkpoint；越早的历史贡献随平均更新次数指数衰减。

3.10.3 本文设置与 EMA 教师的区别

附录 B 设置：

$$\beta=0.9999,\qquad\text{每 32 个优化器步骤更新一次平均参数。}$$

即每次平均更新保留旧平均值的 99.99%，加入当前参数的 0.01%。这个比例针对一次平均更新，不能误写为每个优化器步骤都执行。

3.11 预训练数据和评估协议

3.11.1 数据来源

默认使用 K710 的 20% 类别均衡子集。K710 由 Kinetics-400/600/700 训练集组合而成，并移除与验证集重叠的部分。

默认数据子集较小，主要方便在相同数据条件下重新训练基线，进行受控比较。

扩大语料时使用 K710、Something-Something-v2、Walking Tours 和 PE Video Dataset。Walking Tours 包含较长的第一视角步行视频，PE Video 来自 Perception Encoder 发布的视频数据。

3.11.2 冻结评估

预训练完成后冻结编码器，仅训练下游 probe 和分类器。下游训练使用对应任务的标签。

评估集 缩写 主要能力 本文主要读出方式
ImageNet-1K IN1K 静态物体识别 Attentive probing
Something-Something-v2 SSv2 依赖时间关系的运动理解 Attentive probing
Kinetics-400 K400 视频动作识别，含较多外观和场景线索 平均池化后 linear probing

4. What Matters for Efficient Video Pretraining：设计消融

本章默认使用 ViT-B/16、K710 的 20% 子集。不同消融中的基准数值不完全一致，逐表记录，不能拼接成一条逐步累加的性能提升链。

4.1 Token dropping：对外观和运动产生不同影响

4.1.1 ImageNet 随丢弃率提高而改善

图 4(a) 报告：

丢弃率 $\rho$ ImageNet Top-1
0% 33.9%
30% 39.6%
60% 44.8%
90% 47.4%
95% 47.6%

作者的解释是，随机丢弃同时降低计算并形成强随机增强：模型需要从不同位置的稀疏观察中推断稳定的片段内容。

对逐 token 的前馈层，相关成本大致随保留 token 数变化，95% 丢弃对应该部分约 20 倍的 token 数减少。整个训练流程还包含 patch embedding、注意力及其他开销，不能把这个局部比例直接当成总训练提速。

从 90% 提高到 95% 时，保留 token 减半，准确率基本持平，因此作者选择 95% 为默认值。

4.1.2 运动理解需要更充分训练

SSv2 上，短训练周期中丢弃率超过 0.3 后，准确率会下降。作者发现延长训练可以缓解，较高丢弃率能够追回较低丢弃率的表现，并保留低单步成本。

理解：识别"有手、有杯子"可以依靠零碎外观；判断"手将杯子从左移到右"更依赖跨帧对应。高稀疏度使一次观察中的运动线索更不完整，额外训练可以补偿一部分信号损失。这是作者提出的合理解释，完整机制尚未定量刻画。

4.1.3 均匀随机丢弃优于 tube 丢弃

比较 均匀随机丢弃 Tube 丢弃
IN1K 50.7% 39.6%
SSv2，文中 $\tau=2$ 配置 28.8% 26.4%

Tube 方式在每帧保留相同空间位置，大部分区域会在整个片段中持续不可见；随机丢弃则在不同时间采到不同位置，观察覆盖更分散。

像素重建需要防止邻帧复制捷径，而本方法不重建缺失内容，保留 token 是其全部观察。目标不同，合适的丢弃结构也不同。

4.2 局部视图数量

图 4(b) 报告：

局部视图数 $V$ ImageNet Top-1
4 47.6%
6 49.1%
8 49.2%
10 50.2%
12 49.8%

更多局部视图增加同一视频的一致性约束，每增加一个局部视图只多处理约 29 个 patch token，成本相对小。收益在 10 个左右趋于饱和。

本文默认比较保留 $V=4$；等算力的长训练配置使用 $V=10$。

4.3 时间 patch 聚合并非必需

作者比较：

  • $\tau=2,\rho=0.90$：输入 patch 覆盖两帧，保留 10%。
  • $\tau=1,\rho=0.95$：逐帧 patch，保留 5%。

预训练均从 16 帧开始，两种配置每个视图保留的 token 数相同。

表 1 报告：

Patch 时间尺寸 丢弃率 IN1K SSv2
$\tau=2$ 90% 47.4% 28.8%
$\tau=1$ 95% 50.7% 30.4%

在评估时不丢弃 token，并匹配为 8 个时间位置：$\tau=1$ 输入 8 帧，$\tau=2$ 输入 16 帧。ImageNet 图片则沿时间轴分别重复 8 次和 16 次。

这控制了评估 token 数，但两种视频输入的实际帧数不同，需要保留这个实验条件。

结果支持：输入端不必预先聚合两帧，模型仍能通过后续结构学习有用时间信息。默认采用逐帧 tokenization。

4.4 Block-causal attention 没有表现出精度代价

表 2 在 $\tau=1,\rho=0.95,V=4$、均匀随机丢弃条件下比较：

注意力结构 IN1K Top-1
全双向 50.7%
Block-causal 51.2%

作者据此采用 block-causal 默认结构。

这项直接消融只报告 ImageNet。可以说所报告条件下没有观察到精度下降，不能扩展成所有运动任务和规模都已验证无代价；0.5 个百分点差异也没有配套完整显著性统计。

6. Discussion：贡献、PNC 对应关系与局限

6.1 最重要的方法逻辑

$$\text{显式分布目标承担防塌缩}\longrightarrow\text{减少额外训练结构}\longrightarrow\text{重新选择观察方式和时间注意力}.$$

本文并不只是在旧方法上增加一种正则项；它进一步验证了高比例随机丢弃、逐帧 token 和 block-causal 编码的组合。

两项损失构成一个训练目标；“单个编码器"指共享参数与不依赖目标教师，并不意味着多个视图只需进行一次单视图编码。

6.2 与规则 PNC 背景的对应关系

论文概念 便于理解的 PNC 对应 类比边界
视频编码器 从历史观测提取状态描述 特征通常不可直接解释成位置、速度等物理量
视图一致性 相同场景在不同观测条件下保持稳定描述 裁剪可能丢失局部关键事件，不能直接当成规划不变性
因果 patch 表征 当前状态估计只使用当前和过去输入 不代表已经完成物理因果推断或未来轨迹预测
各向同性 类似从不同方向看统计误差是否均衡 特征方向并不对应车辆纵向、横向
EMA 参数平均 一阶低通滤波式平滑 平滑的是模型参数，不是车辆状态估计

对自动驾驶最有启发的方向，是用大量无标注行车视频预训练编码器，再针对感知、预测或规划训练下游模块。

如果要构建动作条件世界模型，还需要学习：

$$s_{t+1}=f(s_t,a_t),$$

其中 $s_t$ 是状态特征，$a_t$ 是动作。LeVJEPA 的视图来自同一时间窗口，一致性损失没有直接训练这一状态转移关系。

6.3 作者明确保留的局限

  • 运动线索：高丢弃率会降低短训练中的 SSv2 表现，如何在高稀疏度下保留跨帧对应仍需研究。
  • 训练规模：受控比较主要使用较小语料和至 ViT-L 的规模，互联网规模及更大模型尚未系统验证。
  • 大 batch 交互：SIGReg 与超大 batch、大模型的交互还需要刻画。
  • 密集任务：可视化显示语义 patch，但分割、跟踪等实际能力尚未量化。

工程应用还需要额外验证行车域、罕见事件、局部小目标及端到端规划任务。这里是迁移需求，不能当成论文已报告的失败结论。

附录 A. SIGReg 实现与多卡通信

参数或操作 设置

对每个视图，各 worker 先计算本地经验特征函数，再通过一次 all-reduce 汇总，之后计算分布差异统计量。All-reduce 是把各设备的统计值进行全局汇总并返回各设备的通信操作。

核心通信张量大小为：

$$2\times M\times17=2\times1024\times17.$$

其中 2 对应复数的实部和虚部，也就是余弦、正弦统计。该统计张量大小与 batch size 和 embedding 维度无关。这里描述的是 SIGReg 统计通信，不包含通常的模型梯度同步。

在固定 $M$ 和积分节点数时，投影及统计计算随样本数和特征维度线性扩展，但仍有由方向数和节点数带来的常数开销。

投影头具体结构为：

$$\operatorname{Linear}(d,2048)\rightarrow\operatorname{BatchNorm}\rightarrow\operatorname{GELU}\rightarrow\operatorname{Linear}(2048,256).$$

MLP 是多层感知机，通常由线性层与非线性激活组成；这里为两层线性层。GELU 是非线性激活函数。BatchNorm 根据批次统计进行归一化，统计轴及作用不同于编码器的逐 token LayerNorm。

附录 C. 下游读出模块

C.1 Attentive probing

一个可学习 query 通过单层交叉注意力读取冻结编码器的全部输出 token；注意力输出与 query 作残差连接，再经两层 MLP、GELU 和 LayerNorm，并由线性层分类。

只有 probe 和分类器参加下游优化，编码器参数保持冻结。优化超参数沿用 V-JEPA 协议，论文没有逐项重列。

“非线性 probe 更合适"的含义是：预训练目标没有保证每个任务都线性可分，注意力读出能测量表征中可被提取的信息。它也意味着不同 probe 的结果应在相同协议下比较。

C.2 K400 linear probing

先将冻结编码器输出 token 平均池化成单个向量，再训练线性分类器。作者因 K400 训练集较大，使用这一较便宜的读出方式。

最终结论与仍待讨论的问题

核心贡献

  1. 将 LeJEPA 的一致性加 SIGReg 配方用于视频，使训练主体简化为共享编码器和小型投影头。
  2. 在统一重训条件下，以 5.6—20.8 倍更少的总预训练 FLOPs 获得接近或更好的 ImageNet 表现；等算力时取得明显外观识别优势。
  3. 验证极高比例随机丢弃可以兼具计算收益和表征收益，但运动任务需要关注训练长度。
  4. 将 block-causal 约束纳入编码器，在所报告 ImageNet 消融中没有观察到精度损失，为在线表征和后续动态建模提供基础。
  5. 即使只直接监督 CLS，仍出现有语义组织的 patch 特征，值得继续验证密集任务。

理解和应用的条件

高斯目标的理论依据依赖相关风险模型及假设；训练实现通过有限样本、随机方向和数值积分近似该目标。主实验优势对应本文数据、模型规模和冻结读出协议。训练计算节省不等于相同比例的推理时延收益。

主要局限

SSv2 运动理解仍未在等算力比较中领先；大模型、大数据和密集任务验证不足。本文没有给出删除末端 LN、删除投影头、改用球面分布目标等替代方案的消融，也没有直接评估自动驾驶规划能力。
